# 知识库服务（为 AI 设计的分区知识库）

纯 Python + FastAPI 实现，PyCharm 直接可用。所有录入均为**普通中英文输入**，程序自动转换成 JSON 结构与字母数字标记。

## 功能总览

- **四区隔离**：信任区 / 存疑区 / 待审核区 / 申请区（物理目录独立）
- **标记规则**：类型前缀字母（管理员指定）+ 每类型独立序号（P1、P2、L1…，只增不回收）
- **知识五要素**：标题、简介（公开）、详细使用方法、详细使用经验、局限性（后三者受保护）+ 正文
- **四种身份**：管理员（固定名）、AI（固定名）、人类访问方（逐个指定固定名）、匿名
- **AI 权限**：自由调用信任区/存疑区/待审核区（研究用），但**永远不能写库**——一切修改走申请区（强制附理由+证明过程），管理员亲手执行
- **人类访问方**：目录只展示简介 → 按标记申请 → 管理员批准 → 按标记只读 → 随时单项收回或整体踢出（≤1 秒生效）
- **总开关**：手动关闭后一切 HTTP 访问返回 503，本地 CLI 仍可操作（逃生通道）
- **双日志哈希链**：access.log（每次调用）/ admin.log（每次管理行为），防篡改可校验
- **可靠性**：原子写入+重试、历史版本自动备份可回滚、启动自检、外部修改侦测、限流、请求体上限

## 快速开始（PyCharm 一键运行）

日常只需运行上级目录的 **`启动服务.py`**（自动装依赖、首次自动生成密钥、启动服务）；
管理操作用 **`管理菜单.py`**（中文菜单）。本目录是程序本体，一般无需直接操作。

手动方式（等价）：

```bash
pip install -r requirements.txt
python admin_cli.py init      # 创建管理员密钥 + AI 密钥（各显示一次，务必保存）
python -m kb.main             # 启动服务
```

- 目录界面（给对方看）：`http://127.0.0.1:8320/static/catalog.html`
- 管理界面（仅本机）：`http://127.0.0.1:8320/static/admin.html`（用管理员密钥登录）
- 中文菜单（功能最全，总开关关闭时也能用）：`python admin_cli.py`
- 状态速查：`python admin_cli.py status`
- 自检：`python selftest.py`（会写入少量演示数据）

## 日常使用流程

1. `admin_cli.py` → 菜单 4 添加类型（如 python + 字母 P）
2. 菜单 5 录入知识（默认进**待审核区**；缺使用方法/经验/局限性任一字段拒绝入库）
3. 菜单 8 把审核通过的知识移入信任区/存疑区（存疑→信任时会询问哪些经验被证实）
4. 对方打开目录页，勾选知识提交申请；菜单 11 批准并指定固定名称，密钥**仅此一次显示**
5. 菜单 12 随时追加授权 / 收回标记 / 临时授权待审核知识（验证用）/ 吊销访问方
6. 菜单 13 处理 AI 的申请（申请区 REQ）：逐字段确认后执行，AI 端立即可见状态
7. 菜单 14 查日志，菜单 15 回滚误修改

## 给 AI 的接口约定

```bash
# 调用知识（AI 可读全部区，含待审核区）
curl -H "X-API-Key: <AI密钥>" http://127.0.0.1:8320/api/kb/P1

# 提交修改申请（五种动作，理由和证明过程必填）
curl -X POST -H "X-API-Key: <AI密钥>" -H "Content-Type: application/json" \
  -d '{"action":"modify","target":"P1","proposal":"建议补充边界说明",\
       "reason":"为什么改","proof":"验证过程与证据"}' \
  http://127.0.0.1:8320/api/req
# action ∈ modify(修改) / new(新增) / append_experience(追加经验) / move_zone(建议移区) / suspect_to_pending(存疑转待审核)

# 查询自己的申请进度
curl -H "X-API-Key: <AI密钥>" http://127.0.0.1:8320/api/req
```

## 给别人使用

1. 菜单 2 或管理页打开「对外访问」（**重启服务后生效**，绑定 0.0.0.0）
2. 对方浏览器访问 `http://<你的IP>:8320/static/catalog.html`，勾选申请
3. 菜单 11 批准后私下转交密钥
4. 随时菜单 12 踢出。管理端点永远只认 127.0.0.1，网络上够不到
5. 对外使用建议在可信局域网，或在 `kb/config.py` 配置 HTTPS_CERT 启用 HTTPS

## 目录结构

```
zhishiku/
├── kb/                  # 服务包
│   ├── config.py        # 名称、端口、HTTPS、限流等（ADMIN_NAME / AI_NAME 在这里改）
│   ├── main.py          # 入口：python -m kb.main
│   ├── admin_api.py     # 管理端点（仅本机 + 管理密钥）
│   ├── public_api.py    # 目录/申请/调用/AI 申请区
│   ├── store.py         # 分区、标记、索引、历史版本
│   ├── auth.py          # 密钥、授权、吊销
│   ├── reqsys.py        # 申请区 + 访问申请
│   ├── audit.py         # 双日志哈希链
│   └── safeio.py        # 原子写入 + 缓存读取
├── static/              # 目录页 + 管理页
├── admin_cli.py         # 中文管理菜单（功能最全）
├── selftest.py          # 端到端自检
├── data/                # 四个区 + .history 历史版本（可整体备份）
├── meta/                # 开关、密钥哈希、索引、计数器
└── logs/                # access.log / admin.log（哈希链防篡改）
```

## 清理演示数据

selftest.py 会创建演示类型/知识/访问方「测试员」。清理：`python admin_cli.py` → 菜单 9 废弃知识、菜单 12-4 吊销「测试员」；或直接删除 `data/`、`meta/`、`logs/` 后重新 `init`（**密钥会失效，需重新生成并转交**）。
